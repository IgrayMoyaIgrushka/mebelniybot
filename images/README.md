## Как скачать:
1. Кликни на ссылку правой кнопкой мыши
2. Выбери "Сохранить ссылку как..."
3. Сохрани файл с соответствующим именем в папку `images/`

Или можешь использовать свои изображения мебели с теми же именами файлов.
